# Owner-Mode Source Embedding Reuse (S4b)

This dependent contribution adds durable reuse of already retained, bounded S3b excerpts. It does not install an embedding provider, change deployed model/dimension settings, modify the legacy query cache, migrate vectors, activate protected indexing or change ordinary recall. The application owning the connection and supplying the embedding contract is trusted. These APIs are not authorized protected paths; P3/P4 must supply derivative policy, revocation and trusted adapter enforcement before protected use.

## Exact Reuse Contract

`EmbeddingContract(sharing_domain, model_identity, dimensions, preprocessing_sha256)` is immutable. A nonempty explicit host-owned domain and an exact model/artifact identity are required; dimensions are an explicit integer from 1 through 4096. The preprocessing hash identifies the complete document-input contract, including prefix, normalization, truncation/caps, tokenizer/chunk policy and provider configuration that affects vectors. The host must supply truthful identities and change them when behavior changes. A model alias alone is not proof that an artifact or provider remained unchanged. No ambient environment default or dimension guess is used.

The reuse key includes source group, sharing domain, exact model identity, dimensions, preprocessing hash and exact retained excerpt UTF-8 SHA-256. Reuse is deliberately restricted to one trusted source group, even if identical text exists in unrelated sources. Relocation, extraction revision or span changes can reuse identical excerpt bytes in that group, but the new plan/excerpt association is persisted before a reused vector is returned. New text or any contract change misses. A matching hash is also checked against the exact current excerpt bytes through the validated S3b catalogue; existing source/revision/span lineage is not replaced by text deduplication.

## Interface

`SourceEmbeddingStore(existing_connection)` has no constructor side effects. `get(source_key, fingerprint, ordinal, *, contract)` performs an owner-mode read and returns a validated artifact or `None`, without creating tables or binding a new derivative. It is not an ingestion receipt or permission to inject the artifact. `reuse(...)` explicitly attaches the current excerpt's lineage to an existing matching artifact and returns a `reused` receipt, or `None` on a miss without creating optional schema. `put(..., values, *, contract)` creates or exactly reuses an artifact and its lineage atomically. Identical retries create no duplicate vectors or bindings. Conflicting float32 bytes under the same identity refuse instead of overwriting.

Values are explicit list/tuple finite, nonzero, float32-range numbers of exactly the declared dimension; booleans, zero-after-float32-rounding, NaN, infinity and mismatched dimensions refuse. Values are stored as little-endian float32 BLOBs with SHA-256. No text is copied into the cache, no original or full extraction is embedded by this API, and no FTS, working-memory or moment rows are added. Returned values are immutable tuples and sensitive identifiers/values are excluded from representations.

There are at most eight distinct contracts, 1024 artifacts, 1024 lineage bindings and 16 MiB logical vector bytes per source group. These conservative downstream limits are not capacity/quality optima. They never reset through generation selection or a new source revision. There is no eviction/delete API in this contribution; exhausted capacity refuses until reviewed lifecycle work supplies safe retention. SQLite physical page/journal copies are not a logical quota or forensic-erasure guarantee.

`materialize(source_key, fingerprint, ordinal, *, contract, compute)` is an explicit single-owner importer helper: first reuse a committed artifact, otherwise obtain the exact validated retained excerpt, leave the database transaction, call the supplied `compute(text, contract)` once, then validate and persist its result. The callback is mandatory; no model is selected or called implicitly. Caller-owned transactions are refused before callback work; `put`/`reuse` separately support pending caller-owned writes. Callback failures/cancellation propagate without a cache entry and do not alter the current generation. Completed imports and restart/resume reuse durable vectors without another compute call. Concurrent misses or a process dying after an external provider finished but before durable persistence can repeat computation; this is not an exactly-once external-provider guarantee. Hosts must serialize their importer if duplicate concurrent work matters. Conflicting concurrent results refuse rather than silently changing the artifact.

## Failure, Compatibility And Coverage

Two additive optional tables plus a group index preserve every existing S3/S4a and native schema/API. Explicit writes use the existing guarded SQLite ownership/savepoint model; receipts distinguish committed and pending. Read methods never migrate. Strict schema/type/byte/row limits, checksums, source-group/lineage binding and exact contract identity are audited before returning artifacts. Reserved temp names, partial/unknown schema, triggers/index changes, orphan records, malformed text and invalid vectors refuse without repair. New metadata projections return bounded bytes before strict ASCII decoding; raw locking/storage failures remain explicit. The owning process can issue raw SQL and is not sandboxed by this catalogue.

This is a durable artifact and bounded callback seam, not a complete document importer, model-versioned generation controller, semantic-search index, universal policy cache or protected-mode readiness. A generation's evidence-completed checkpoint alone does not certify embeddings; the host must bind model/preprocessing identity into its generation workflow. Full A13/A14, real provider/adaptor integration, protected derivative invalidation/revocation, and source-wide retention remain separate acceptance gates. Tests use synthetic callbacks/vectors, disposable databases and explicit call counters, never live models or private stores.
